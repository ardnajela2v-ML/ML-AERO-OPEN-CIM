01 · Visión de sistema

Arquitectura general del sistema WAsP

WAsP (Wind Atlas Analysis and Application Program) es el estándar de facto mundial para evaluación de recursos eólicos. Desarrollado por DTU Wind (antes Risø), implementa la Wind Atlas Methodology: un proceso de dos pasos —"subir" y "bajar"— que desacopla el clima eólico medido de las condiciones topográficas locales, permitiendo extrapolar predicciones a cualquier sitio.

Datos observados
Serie histórica de viento (OMC), topografía (contornos), rugosidad superficial (polígonos)
02 · ANÁLISIS
Climatología
Histograma sectorial → Weibull A, k por sector
03 · SUBIR ↑
Generalización
Eliminar efectos locales → Clima Eólico Generalizado (wind atlas)
04 · BAJAR ↓

Re-introducir efectos del sitio objetivo → Clima local predicho
05 · SALIDA
AEP + Mapa
Velocidad media, AEP, Weibull, RIX, ΔRIX por punto de recurso

02 · Física del flujo

Matemática del modelo de flujo microscala

El núcleo de WAsP resuelve el campo de velocidades de viento en la capa límite atmosférica (ABL) sobre terreno heterogéneo. El enfoque es linealización de Navier-Stokes bajo condiciones estacionarias y neutras.

Perfil logarítmico de velocidad (terreno plano)

La base teórica es el perfil log-lineal de la capa superficial de Monin-Obukhov. En condiciones neutras:

// Perfil logarítmico de viento — ley de la pared U(z) = (u* / κ) · ln(z / z₀) Donde: U(z) = velocidad del viento a altura z [m/s] u* = velocidad de fricción [m/s] κ = constante de von Kármán ≈ 0.4 [-] z = altura sobre el suelo [m] z₀ = longitud de rugosidad [m]

Ley de arrastre geostrófico

Para conectar el viento medido a baja altura con el viento geostrófico libre de efectos de superficie (el "viento atlas"):

G = u* / κ · √[ (ln(u*/fz₀) - A)² + B² ] f = 2Ω·sin(φ) parámetro de Coriolis Ω = 7.27×10⁻⁵ rad/s velocidad angular Tierra φ = latitud del sitio A ≈ 1.8, B ≈ 4.5 (constantes de Blackadar-Tennekes)

La transformación "subir" elimina los efectos de z₀ local y orografía local. La transformación "bajar" los reintroduce para el sitio predicho.

Velocidad de fricción y estrés cortante

u* = U(z) · κ / ln(z / z₀) // Para extrapolación vertical entre altura de medición z₁ y z₂: U(z₂) = U(z₁) · ln(z₂/z₀) / ln(z₁/z₀)
03 · Estadística del viento

Distribución de Weibull y Clima Eólico Generalizado

WAsP representa la distribución de velocidades por sector como una Distribución de Weibull de 2 parámetros. El Clima Eólico Generalizado (CWG) es un conjunto de distribuciones Weibull por sector, referidas a terreno ideal.

// Función densidad de probabilidad de Weibull f(U) = (k/A) · (U/A)^(k-1) · exp[-(U/A)^k] Donde: A = parámetro de escala [m/s] (≈ velocidad media / Γ(1+1/k)) k = parámetro de forma [-] (típico: 1.5 – 3.0 para viento) U = velocidad del viento [m/s] Γ = función Gamma de Euler
// Velocidad media a partir de parámetros Weibull Ū = A · Γ(1 + 1/k) // Densidad de potencia media: P̄ = ½ρ · A³ · Γ(1 + 3/k) [W/m²]
// Función de distribución acumulada F(U) = 1 - exp[-(U/A)^k] // Frecuencia de velocidades en intervalo [U₁, U₂]: p(U₁ ≤ U ≤ U₂) = F(U₂) - F(U₁)

Estructura del Clima Eólico Generalizado (CWG)

El CWG es un array de forma [n_sectores × (A, k, frecuencia)]. WAsP típicamente usa 12 sectores de 30°:

CWG = { sector_i: { freq_i: frecuencia de ocurrencia del sector i [0-1] A_i: parámetro de escala Weibull del sector [m/s] k_i: parámetro de forma Weibull del sector [-] } para i = 0°, 30°, 60°, ..., 330° } Restricción: Σ freq_i = 1

Ajuste de Weibull (fitting)

El ajuste se hace por Máxima Verosimilitud (MLE) o Mínimos Cuadrados sobre el histograma empírico. La solución MLE para k requiere iteración numérica:

// Estimación por máxima verosimilitud k_MLE: resuelve numéricamente Σ Uᵢᵏ·ln(Uᵢ) / Σ Uᵢᵏ - (1/k) - (1/N)·Σ ln(Uᵢ) = 0 A_MLE = (1/N · Σ Uᵢᵏ)^(1/k)
04 · Orografía

Orografía: el modelo BZ (Bessel-Zooming)

El modelo BZ (Troen, 1990) es el corazón del cálculo orográfico de WAsP. Resuelve las ecuaciones linealizadas de flujo potencial perturbado sobre una grilla polar de alta resolución centrada en el punto de cálculo.

Fundamento: ecuaciones de flujo perturbado linealizado

// Descomposición del campo de velocidades u(x,y,z) = U₀(z) + u'(x,y,z) // componente media + perturbación w(x,y,z) = w'(x,y,z) // Bajo linealización (|u'| << U₀), las ecuaciones RANS se reducen a: ∂u'/∂x + ∂v'/∂y + ∂w'/∂z = 0 // continuidad U₀·∂u'/∂x = -∂p'/∂x // momento x U₀·∂w'/∂x = -∂p'/∂z // momento z

Speed-up orográfico (Δs)

// Speed-up fraccional en la cima de una colina Δs = u'(x_cima, z) / U₀(z) // La altura de máximo speed-up l está relacionada con la escala L de la colina: l ≈ L / 2π (estimación de Troen) // Speed-up máximo típico para colina suave: Δs_max ≈ H / (π·L) donde H = altura, L = semi-longitud de ladera

Grilla polar de Zooming (BZ)

WAsP discretiza el terreno en una grilla polar centrada en el punto de cálculo. La resolución radial aumenta hacia el centro (zooming), optimizando detalle local sin explotar el costo computacional:

// Distribución radial de la grilla zooming r_n = R · (n/N)^α n = 1, ..., N Donde: R = radio máximo de la grilla (≈ 20 km, contornos > 20 km se ignoran) N = número de anillos α > 1 controla la distribución (mayor α → más resolución al centro) // La grilla tiene: - N anillos radiales - M sectores angulares (típico: 72 → resolución 5°) - Resolución total: N × M celdas

Procesamiento de contornos a grilla BZ

Capa Límite Interna (IBL) en cambio de rugosidad

Cuando el viento cruza un cambio de rugosidad (z₀₁ → z₀₂), la capa límite no se adapta instantáneamente. La IBL crece aguas abajo y la adaptación puede percibirse a 10 km de distancia a 100 m de altura.

// Crecimiento de la capa límite interna (IBL) h_IBL(x) = κ · x / ln(x/z₀₂) (aproximación simple) // Modelo de Elliott (1958), más preciso: h_IBL(x) · [ln(h_IBL/z₀₂) - 1] = 0.9 · x Donde x = distancia aguas abajo del cambio de rugosidad
// Perfil de velocidad en la zona de transición rugosidad Para z < h_IBL(x): U(z) = (u*₂/κ) · ln(z/z₀₂) // adapado a z₀₂ Para z > h_IBL(x): U(z) = (u*₁/κ) · ln(z/z₀₁) // aún influenciado por z₀₁

Modelo multirugosidad (WAsP)

WAsP divide el entorno en sectores angulares. Para cada sector integra el efecto de múltiples cambios de rugosidad en serie, acumulando el efecto IBL:

Velocidad efectiva en el mástil (sector θ): U_eff(z, θ) = U_geo(θ) · ∏ᵢ [F_rgh(z₀ᵢ, z₀ᵢ₊₁, xᵢ, z)] Donde F_rgh es el factor de corrección IBL por cada cambio i
06 · Energía

Producción de energía: AEP y curvas de potencia

AEP por integración Weibull × curva de potencia

La Producción Anual de Energía (AEP) se calcula integrando la curva de potencia P(U) del aerogenerador contra la distribución de probabilidad de velocidades f(U):

// Producción de energía esperada por sector E_sector = T · freq_sector · ∫₀^∞ P(U) · f(U; A, k) dU // AEP total: AEP = Σᵢ E_sectorᵢ [kWh/año] Donde: T = 8760 h/año P(U) = curva de potencia del aerogenerador [kW] f(U) = Weibull PDF del sector i freq_i = frecuencia de ocurrencia del sector i
// Versión discreta (bins de velocidad) AEP ≈ T · Σⱼ P(Uⱼ) · p(Uⱼ) [kWh/año] p(Uⱼ) = F(Uⱼ + ΔU/2) - F(Uⱼ - ΔU/2) // probabilidad en bin j

Densidad de potencia media

P̄_dens = ½ · ρ_aire · Ū³ [W/m²] // ρ_aire varía con altitud y temperatura: ρ = P_atm / (R_d · T) R_d = 287 J/(kg·K), T en Kelvin ρ ≈ 1.225 kg/m³ a 15°C, nivel del mar

Factor de capacidad (CF)

CF = AEP / (P_nominal × 8760) [-] // Rango típico: CF_bueno > 0.35 CF_excelente > 0.45
07 · Efectos de estela

Efectos de estela: PyWake y modelos de déficit

PyWake es el motor open-source de DTU para calcular interacciones de estela en parques eólicos. Implementa la cadena: Site → WindTurbines → WakeDeficitModel → SuperpositionModel → AEP.

Modelo N.O. Jensen (NOJ) — Top-hat, 1983

El modelo más simple y ampliamente usado. Asume expansión lineal de la estela con perfil uniforme ("sombrero de copa"):

// Velocidad en la estela V = U₀ · [1 - 2a · (r₀ / (r₀ + k·x))²] Donde: U₀ = velocidad libre corriente aguas arriba [m/s] a = factor de inducción axial = (1 - √(1-Cт))/2 r₀ = radio del rotor [m] x = distancia axial aguas abajo [m] k = constante de entrainment ≈ 0.04 (offshore) a 0.1 (onshore) Cт = coeficiente de empuje de la turbina [-]
// Déficit de velocidad fraccional δV/U₀ = 2a · (r₀ / (r₀ + k·x))² // Radio de la estela aguas abajo: r_w(x) = r₀ + k·x

Modelo Bastankhah-Porté-Agel (2014) — Gaussiano

Modelo analítico con perfil Gaussiano, conserva masa y cantidad de movimiento:

// Déficit de velocidad con perfil Gaussiano ΔU(x,r) = U₀ · (1 - √(1 - Cт/(8·σ²/D²))) · exp(-r²/(2σ²)) // Expansión del ancho de estela: σ(x)/D = k* · x/D + ε Donde: r = distancia radial al eje de estela [m] σ = anchura del Gaussiano [m] D = diámetro del rotor [m] k* = coeficiente de expansión de estela ≈ 0.04 ε = ε₀ que depende de Cт (evita singularidad en x=0)

Superposición de estelas múltiples

// Suma lineal (LinearSum) ΔU_total = Σᵢ ΔUᵢ // simple pero sobreestima // Suma cuadrática (SquaredSum — Katic 1986) ΔU_total = √(Σᵢ ΔUᵢ²) // más conservadora, preferida // Velocidad efectiva resultante: U_eff = U₀ · (1 - ΔU_total/U₀)

08 · Complejidad del terreno

Índice de Rugosidad RIX y ΔRIX

El modelo BZ tiene validez limitada en terrenos de pendiente pronunciada. WAsP cuantifica esto con el índice RIX para alertar sobre posibles errores en sitios con orografía compleja.

// Ruggedness Index (RIX) RIX = fracción del terreno circundante que supera la pendiente crítica Pendiente crítica θ_c ≈ 0.3 rad (≈ 17°) RIX = (1/2π) · ∫₀^2π H(tan θ(φ) - tan θ_c) dφ Donde H() = función de Heaviside (1 si condición verdadera)
// Delta-RIX: diferencial entre sitio de predicción y sitio de referencia ΔRIX = RIX_prediccion - RIX_referencia [%] // Guías de interpretación: |ΔRIX| < 5% → predicción fiable |ΔRIX| 5-10% → incertidumbre moderada |ΔRIX| > 10% → WAsP puede sobre/sub-estimar significativamente

Cuando ΔRIX > 0, WAsP tiende a sobreestimar la velocidad. La corrección empírica de Bowen-Mortensen:

U_corr = U_WAsP / (1 + β · ΔRIX) β ≈ 3.5 (calibrado empíricamente para terrenos complejos)
09 · Arquitectura del sistema

Arquitectura del sistema AERO OPEN CIM

AERO OPEN CIM es una plataforma de prefactibilidad eólica de ciclo completo. Integra cinco módulos científicos desacoplados que procesan datos desde la adquisición del recurso hasta la evaluación tecnoeconómica final. Cada módulo expone una API REST estándar; el frontend SPA los orquesta sin acoplar lógica de negocio.

Pipeline de datos y decisión

① Recurso Eólico

Entrada: series horarias MERRA-2/ERA5, datos de estación (CERTE).
Proceso: QC, sincronización UTC, MCP, Weibull por sector.
Salida: recurso validado, estadísticos direccionales, hindcast.

② Diseño de Parque

Entrada: recurso validado, polígono del predio, catálogo de turbinas.
Proceso: Kriging espacial, generación de layouts, simulación de estelas, economía por candidato.
Salida: alternativas de layout con AEP_P50/P90, CAPEX, VAN, LCOE.

③ Selección TOPSIS+AHP

Entrada: alternativas de layout con métricas técnicas y económicas.
Proceso: normalización vectorial, pesos AHP, distancias ideal/anti-ideal, SMAA de robustez.
Salida: ranking multicriterio con score de proximidad y análisis de sensibilidad.

④ Evaluación Tecnoeconómica

Entrada: layout ganador, parámetros financieros, PML horario.
Proceso: cashflows 25 años, inflación Fisher, WACC, apalancamiento equity.
Salida: LCOE nominal/real, VAN, TIR, payback descontado, tabla de flujos anuales.

⑤ Validación y Exportación

Entrada: resultados del proyecto activo.
Proceso: métricas de validación cruzada, benchmarking de pronóstico, exportación de datos.
Salida: reportes en JSON/CSV/KML, resumen ejecutivo del proyecto.

Principio de diseño: los módulos comparten estado a través de una sesión en memoria del servidor (reemplazable por Redis en producción multi-usuario). Cada módulo puede ejecutarse de forma independiente vía API REST — el frontend es una vista opcional, no un requisito.

    """
    
    def __init__(self, A: float, k: float):
        self.A = A   # escala [m/s]
        self.k = k   # forma [-]
    
    def pdf(self, U: np.ndarray) -> np.ndarray:
        """f(U) — Función densidad de probabilidad (Ec. 4)"""
        A, k = self.A, self.k
        return (k/A) * (U/A)**(k-1) * np.exp(-(U/A)**k)
    
    def cdf(self, U: np.ndarray) -> np.ndarray:
        """F(U) — Función distribución acumulada (Ec. 6)"""
        return 1 - np.exp(-(U/self.A)**self.k)
    
    def mean_speed(self) -> float:
        """Ū = A · Γ(1 + 1/k) (Ec. 5)"""
        return self.A * gamma(1 + 1/self.k)
    
    def mean_power_density(self, rho: float = 1.225) -> float:
        """P̄_dens = ½ρ·A³·Γ(1+3/k) [W/m²] (Ec. 5, 16)"""
        return 0.5 * rho * self.A**3 * gamma(1 + 3/self.k)
    
    def bin_probability(self, U_low: float, U_high: float) -> float:
        """Probabilidad en intervalo [U_low, U_high]"""
        return self.cdf(U_high) - self.cdf(U_low)
    
    def extrapolate_A(self, z1: float, z2: float,
                       z0: float = 0.05) -> 'WeibullDistribution':
        """
        Extrapolación vertical del parámetro A con perfil logarítmico (Ec. 3).
        Asume k constante con la altura (aproximación WAsP).
        """
        ratio = np.log(z2/z0) / np.log(z1/z0)
        return WeibullDistribution(A=self.A * ratio, k=self.k)

core/geostrophic.py — Transformación up/down

import numpy as np

KAPPA  = 0.4    # constante von Kármán
A_CONST = 1.8   # constante Blackadar-Tennekes
B_CONST = 4.5

def u_star_from_profile(U_obs: float, z_obs: float, z0: float) -> float:
    """
    Calcula velocidad de fricción u* desde perfil log (Ec. 3).
    U_obs: velocidad observada a altura z_obs
    z_obs: altura del anemómetro [m]
    z0:    rugosidad del terreno en el mástil [m]
    """
    return U_obs * KAPPA / np.log(z_obs / z0)

def geostrophic_wind(u_star: float, f: float, z0: float) -> float:
    """
    Calcula viento geostrófico G a partir de u* (Ec. 2).
    f = 2Ω·sin(latitud) — parámetro de Coriolis
    """
    log_term = np.log(u_star / (f * z0))
    G = (u_star / KAPPA) * np.sqrt((log_term - A_CONST)**2 + B_CONST**2)
    return G

def coriolis_f(lat_deg: float) -> float:
    """Parámetro de Coriolis para latitud dada [rad/s]"""
    OMEGA = 7.2921e-5  # rad/s
    return 2 * OMEGA * np.sin(np.radians(lat_deg))

def wind_up(U_obs: float, z_obs: float, z0_mast: float,
           lat: float, z0_neutral: float = 0.05) -> dict:
    """
    SUBIR ↑: eliminar efectos locales del mástil.
    Devuelve el clima eólico generalizado (geostrófico).
    
    Paso de generalización: para cada sector, calcular u*, luego G,
    y almacenar como distribución Weibull de G (el "atlas").
    """
    f   = coriolis_f(lat)
    u_s = u_star_from_profile(U_obs, z_obs, z0_mast)
    G   = geostrophic_wind(u_s, f, z0_mast)
    return {'G': G, 'u_star': u_s, 'f': f}

def wind_down(G: float, z_target: float, z0_target: float,
             lat: float) -> float:
    """
    BAJAR ↓: aplicar efectos del sitio objetivo.
    Dado G (atlas), calcular U a altura z_target en terreno z0_target.
    
    Resolver iterativamente u* dado G y z0_target,
    luego extrapolar con perfil log a z_target.
    """
    f = coriolis_f(lat)
    # Resolver u* numéricamente de la ecuación de arrastre (Ec. 2)
    from scipy.optimize import brentq
    def eq(u_s):
        log_t = np.log(u_s / (f * z0_target))
        G_calc = (u_s / KAPPA) * np.sqrt((log_t - A_CONST)**2 + B_CONST**2)
        return G_calc - G
    u_star_site = brentq(eq, 0.01, 5.0)
    U_target = (u_star_site / KAPPA) * np.log(z_target / z0_target)
    return U_target

import numpy as np
import xarray as xr
from py_wake.site.xrsite import XRSite

def build_xrsite_from_cwg(cwg: dict) -> XRSite:
    """
    Construye un objeto XRSite de PyWake desde el Clima Eólico
    Generalizado (CWG) calculado por el motor microscala.
    
    cwg: dict con clave=sector[°], valor={'A':..., 'k':..., 'freq':...}
    
    El sitio requiere P(wd, ws): probabilidad de cada (dirección, velocidad)
    construida desde los parámetros Weibull A(wd), k(wd), freq(wd) por sector.
    """
    sectors = sorted(cwg.keys())
    A_arr   = np.array([cwg[s]['A']    for s in sectors])
    k_arr   = np.array([cwg[s]['k']    for s in sectors])
    f_arr   = np.array([cwg[s]['freq'] for s in sectors])
    f_arr  /= f_arr.sum()  # normalizar
    
    ws = np.arange(0, 26, 1.0)  # bins 0-25 m/s
    wd = np.array(sectors, dtype=float)
    
    # Calcular P(wd, ws): Weibull por sector
    P = np.zeros((len(wd), len(ws)))
    for i, (A, k, f) in enumerate(zip(A_arr, k_arr, f_arr)):
        P[i] = f * (k/A) * (ws/A+1e-9)**(k-1) * np.exp(-(ws/A)**k)
        P[i] /= P[i].sum() + 1e-12
        P[i] *= f
    
    ds = xr.Dataset({
        'P': xr.DataArray(P, dims=['wd', 'ws'],
                         coords={'wd': wd, 'ws': ws})
    })
    return XRSite(ds)

import numpy as np
from .weibull import WeibullDistribution

HOURS_PER_YEAR = 8760

def calc_aep(cwg: dict, power_curve_fn, U_cut_in: float = 3,
             U_cut_out: float = 25, dU: float = 0.5,
             rho: float = 1.225) -> float:
    """
    Calcula AEP [kWh/año] por integración numérica Weibull × curva de potencia.
    Ecuación de referencia: Ec. 14, 15.
    
    cwg: dict sectorial {sector_deg: {'A': float, 'k': float, 'freq': float}}
    power_curve_fn: función callable P(U) → potencia en W
    dU: ancho de bin de velocidad [m/s]
    """
    U_bins = np.arange(U_cut_in, U_cut_out + dU, dU)
    aep_total = 0.0
    
    for sector, params in cwg.items():
        wb  = WeibullDistribution(A=params['A'], k=params['k'])
        freq= params['freq']  # fracción de tiempo en este sector
        
        # Corrección por densidad del aire (si diferente de referencia)
        rho_factor = rho / 1.225
        
        for U in U_bins:
            p_U  = wb.bin_probability(U - dU/2, U + dU/2)
            P_kW = power_curve_fn(U) / 1000 * rho_factor  # W→kW
            aep_total += HOURS_PER_YEAR * freq * p_U * P_kW
    
    return aep_total  # [kWh/año]


def capacity_factor(aep_kwh: float, rated_power_kw: float) -> float:
    """CF = AEP / (P_nominal × 8760) — Ec. 17"""
    return aep_kwh / (rated_power_kw * HOURS_PER_YEAR)


def air_density(elevation_m: float, T_K: float = 288.15) -> float:
    """
    Densidad del aire con corrección altimétrica (ISA estándar).
    Ec. 16: ρ = P_atm / (R_d · T)
    """
    Rd    = 287.058  # J/(kg·K)
    g     = 9.80665  # m/s²
    L     = 0.0065   # K/m tasa de enfriamiento
    P0    = 101325  # Pa presión nivel del mar
    T_eff = T_K - L * elevation_m
    P_atm = P0 * (T_eff / T_K) ** (g / (Rd * L))
    return P_atm / (Rd * T_eff)

16 · Interpolación espacial

Kriging geoestadístico — interpolación espacial

Kriging es el estimador lineal no sesgado de mínima varianza (BLUP) para variables regionalizadas. En AERO se usa para generar mapas continuos de velocidad media del viento, inversión inicial (CAPEX/MW) y VAN a partir de los puntos de reanálisis MERRA-2 / ERA5, produciendo superficies suavizadas con cuantificación de incertidumbre.

Semivariograma experimental

La función semivariograma γ(h) mide cómo varía la dispersión entre pares de puntos separados una distancia h:

γ(h) = (1 / 2·N(h)) · Σ [Z(xᵢ) − Z(xᵢ+h)]² donde N(h) = número de pares de puntos con separación ≈ h

Se ajusta un modelo teórico al semivariograma experimental. Los modelos más usados en AERO son:

Esférico

γ(h) = C₀ + C·[1.5·(h/a) − 0.5·(h/a)³] para h ≤ a; γ(h) = C₀ + C para h > a. Sill = C₀+C, range = a. El más común en recurso eólico.

Exponencial

γ(h) = C₀ + C·[1 − exp(−h/a)]. Alcanza el sill asintóticamente. Adecuado para variables con correlación que decae gradualmente.

Gaussiano

γ(h) = C₀ + C·[1 − exp(−h²/a²)]. Variación muy suave cerca del origen. Útil para variables con alta continuidad espacial.

Kriging Ordinario (OK)

Asume media estacionaria desconocida. Estima Z*(x₀) como combinación lineal de los N vecinos más cercanos:

Z*(x₀) = Σᵢ λᵢ · Z(xᵢ) sujeto a: Σᵢ λᵢ = 1 Sistema de ecuaciones (en forma matricial): [Γ 1] [λ] [γ₀] [1ᵀ 0] [μ] = [1 ] donde Γᵢⱼ = γ(xᵢ − xⱼ), γ₀ᵢ = γ(x₀ − xᵢ) Varianza de kriging: σ²K = Σᵢ λᵢ·γ₀ᵢ + μ

17 · Parque eólico

Layout de parque eólico y optimización de micrositing

El módulo Parque de AERO calcula la disposición óptima de aerogeneradores dentro de un polígono de proyecto, considerando restricciones topográficas, distancias mínimas de separación, efectos de estela y AEP máximo como función objetivo.

Restricciones de layout

Setback mínimo

Distancia mínima entre turbinas: 3–5D en dirección transversal, 5–9D en dirección del viento dominante (D = diámetro del rotor).

RIX local

Cada posición candidata se penaliza si RIX > 30% o ΔRIX respecto a la estación de medición > 5%. Terreno complejo requiere CFD.

Polígono de proyecto

Contorno GeoJSON definido por el usuario. Las posiciones deben estar dentro del polígono y a >500m del borde (configurable).

Capacidad objetivo

N_turbinas = P_parque / P_nominal. El optimizador maximiza AEP total para un N fijo dentro del polígono.

AEP del parque con pérdidas de estela

AEP_parque = Σᵢ AEPᵢ_wake donde AEPᵢ_wake se calcula con velocidad efectiva en turbina i: U_eff,i = U_free − Σⱼ≠ᵢ ΔUⱼ→ᵢ ΔUⱼ→ᵢ = déficit de velocidad de turbina j sobre turbina i = Uⱼ · (1 − √(1 − Ct/2)) · (r_w / (r_w + k·x))² r_w = radio de estela en distancia x: r_w = r₀ + k·x k = constante de expansión de estela (0.04 offshore, 0.075 onshore)

18 · Sistema híbrido

Sistema híbrido: viento + solar + almacenamiento

El módulo Sistema Híbrido modela la operación conjunta de generación eólica, fotovoltaica y almacenamiento en batería (BESS). Calcula el perfil horario de generación, el estado de carga (SOC), la energía vertida (curtailment) y las métricas económicas del sistema integrado.

Modelo fotovoltaico (irradiancia → potencia)

P_pv(t) = η_pv · A_pv · G_eff(t) · [1 − β_T · (T_cell − T_ref)] G_eff = irradiancia efectiva sobre el plano inclinado (W/m²) = GHI · f_inclinación(tilt, azimut, δ, ω) T_cell = T_amb + (NOCT − 20) · G_eff / 800 η_pv = eficiencia del módulo (típico 0.18–0.22) β_T = coeficiente de temperatura (típico −0.004 /°C) T_ref = 25°C (STC)

Modelo de batería (SOC)

SOC(t+1) = SOC(t) + [P_carga(t)·η_c − P_descarga(t)/η_d] · Δt / E_cap Restricciones: SOC_min ≤ SOC(t) ≤ SOC_max (típico 0.1 – 0.9) 0 ≤ P_carga(t) ≤ P_max_carga 0 ≤ P_descarga(t) ≤ P_max_desc η_c = eficiencia de carga (típico 0.95) η_d = eficiencia de descarga (típico 0.95) E_cap = capacidad nominal (MWh)

Retorna: SOC_series, P_bess, curtailment, deficit """ E_cap = bess_params['E_cap_MWh'] P_max = bess_params['P_max_MW'] eta_c = bess_params['eta_charge'] eta_d = bess_params['eta_discharge'] soc_0 = bess_params['soc_init'] n = len(P_wind) soc = np.zeros(n+1); soc[0] = soc_0 P_bess = np.zeros(n) curtail = np.zeros(n) deficit = np.zeros(n) for t in range(n): surplus = P_wind[t] + P_pv[t] - P_demand[t] if surplus > 0: # exceso → cargar batería charge = min(surplus, P_max, ((0.9-soc[t])*E_cap)/eta_c) soc[t+1] = soc[t] + charge*eta_c/E_cap curtail[t] = surplus - charge else: # déficit → descargar batería discharge = min(-surplus, P_max, (soc[t]-0.1)*E_cap*eta_d) soc[t+1] = soc[t] - discharge/(E_cap*eta_d) deficit[t] = -surplus - discharge P_bess[t] = -discharge return soc[:-1], P_bess, curtail, deficit

Fracción de horas con P_suministro ≥ P_demanda. Indicador de firmeza del suministro híbrido.

21 · Demanda a largo plazo

Demanda eléctrica a largo plazo (25 años)

La proyección de demanda eléctrica a 25 años es insumo fundamental del análisis tecnoeconómico. AERO implementa tres enfoques complementarios: regresión econométrica, modelos de elasticidad y simulación de Monte Carlo para capturar la incertidumbre estructural.

Modelo de regresión con variables macro

ln(D_t) = α + β₁·ln(PIB_t) + β₂·ln(P_elec_t) + β₃·T_t + β₄·D_{t-1} + ε_t Donde: D_t = demanda de energía eléctrica (GWh) PIB_t = Producto Interno Bruto (MUSD o MXN real) P_elec_t = precio promedio de electricidad ($/kWh) T_t = temperatura media anual (proxy de climatización) β₁ = elasticidad ingreso (típico 0.8–1.2 en México) β₂ = elasticidad precio (típico −0.2 a −0.5)

Curva de duración de carga (LDC)

LDC(h) = demanda ordenada de mayor a menor sobre las 8760 h del año Factor de carga = D_media / D_pico Factor de forma = D_pico / D_media = 1 / Factor de carga Energía anual = ∫₀^8760 P(t) dt ≈ Σ_h P(h)·1h [GWh/año]

Proyección con Monte Carlo

import numpy as np def demand_mc_forecast(D0, cagr_mu, cagr_std, n_years=25, n_sim=5000): """ Proyección estocástica de demanda eléctrica. cagr_mu: CAGR esperado (ej. 0.035 = 3.5%) cagr_std: incertidumbre del CAGR (ej. 0.008) """ np.random.seed(42) results = np.zeros((n_sim, n_years)) for i in range(n_sim): cagr = np.random.normal(cagr_mu, cagr_std) D = D0 for y in range(n_years): D *= (1 + cagr + np.random.normal(0, 0.01)) results[i, y] = D p10 = np.percentile(results, 10, axis=0) p50 = np.percentile(results, 50, axis=0) p90 = np.percentile(results, 90, axis=0) return p10, p50, p90
22 · Precios de electricidad

Precios PML — modelo estocástico 25 años

El Precio Marginal Local (PML) es el precio de la energía en el mercado mayorista de electricidad de México (MEM, CENACE). AERO modela su evolución a 25 años para valorizar la producción del proyecto bajo incertidumbre de mercado.

Componentes del PML

Energía

Precio de la energía en el nodo de referencia. Determinado por el costo marginal de la unidad despachante.

Pérdidas

Factor de pérdidas marginales por transmisión entre el nodo del generador y el nodo de referencia. Puede ser >1 o <1.

Congestión

Diferencial de precio por restricciones en la red de transmisión. Altamente volátil. Puede representar ±30% del PML total.

Modelo de reversión a la media (Ornstein-Uhlenbeck)

dP_t = κ · (μ - P_t) · dt + σ · dW_t Discretizado (Euler-Maruyama): P_{t+1} = P_t + κ·(μ − P_t)·Δt + σ·√Δt·Z_t, Z_t ~ N(0,1) Parámetros calibrados con histórico PML horario CENACE: κ (velocidad de reversión) ~ 0.1–0.3 diario μ (precio de largo plazo) ~ precio promedio histórico ajustado por inflación y penetración renovable σ (volatilidad) ~ desv. estándar de cambios en ln(P_t) Modelo extendido con estacionalidad: μ_t = μ₀ · (1 + α·cos(2π·t/8760) + β·cos(2π·t/168))

Calibración y simulación Monte Carlo

import numpy as np from scipy.optimize import minimize def calibrate_ou(pml_series): """Calibra parámetros OU por máxima verosimilitud.""" dt = 1/8760 # Δt = 1 hora en fracción de año x = pml_series[:-1]; y = pml_series[1:] def neg_ll(params): kappa, mu, sigma = params if kappa <= 0 or sigma <= 0: return np.inf E = x * np.exp(-kappa*dt) + mu*(1-np.exp(-kappa*dt)) V = sigma**2*(1-np.exp(-2*kappa*dt))/((2*kappa)) return 0.5*np.sum(((y-E)**2)/V + np.log(V)) res = minimize(neg_ll, [0.2, pml_series.mean(), pml_series.std()], method='Nelder-Mead') return dict(zip(['kappa','mu','sigma'], res.x)) def simulate_pml(params, n_years=25, n_sim=3000): n_steps = n_years * 8760; dt = 1/8760 paths = np.zeros((n_sim, n_steps)) paths[:, 0] = params['mu'] for t in range(1, n_steps): dW = np.random.normal(0, np.sqrt(dt), n_sim) paths[:, t] = (paths[:, t-1] + params['kappa']*(params['mu']-paths[:, t-1])*dt + params['sigma']*dW) return paths.clip(0) # precios no negativos

El módulo Energy Lab consolida el balance energético completo del proyecto: producción bruta, pérdidas por categoría, energía neta inyectada a la red, factor de capacidad y curvas de duración. Es el nexo entre el recurso eólico y el análisis económico.

24 · Economía del proyecto

Análisis Tecnoeconómico completo

El módulo Análisis Tecnoeconómico de AERO calcula la viabilidad financiera del proyecto a través de los indicadores estándar de la industria: LCOE, VAN, TIR, Payback, y análisis de sensibilidad. Integra proyecciones de demanda, precios PML, AEP neto y estructura de costos del proyecto.

Estructura de costos CAPEX / OPEX

CAPEX de diseño

Diseño y TOPSIS usan el benchmark IRENA onshore 2024: 1,041 USD/kW de costo total instalado, con 75% asignado a aerogeneradores. La evaluación tecnoeconómica conserva su escenario editable independiente.

CAPEX BOP

Balance of Plant: cimentaciones, red de media tensión, subestación, caminos. ~25–35% del CAPEX total.

OPEX fijo

Mantenimiento mayor y menor, seguro, operación. Típico: 15–25 USD/MWh o 12–18 kUSD/MW·año.

OPEX variable

Repuestos no planificados, arrendamiento de tierra (~1–3 USD/MWh). Escala con la generación real.

LCOE — Costo Nivelado de Energía

LCOE = (CAPEX · CRF + OPEX_fijo) / AEP_neto + OPEX_variable CRF = r · (1+r)^n / [(1+r)^n − 1] (Capital Recovery Factor) r = tasa de descuento (WACC: 7–12% para proyectos eólicos México) n = vida útil del proyecto (típico 25 años) Ejemplo: CAPEX = 1000 USD/kW → 50 MUSD para 50 MW OPEX_fijo = 750 kUSD/año AEP_neto = 180,000 MWh/año (CF = 41%) WACC = 9%, n = 25 años CRF = 0.1018 LCOE = (50,000·0.1018 + 750) / 180,000 = 32.7 USD/MWh

VAN, TIR y Payback

VAN = −CAPEX + Σ_{t=1}^{n} [CF_t / (1+r)^t] donde CF_t = Ingresos_t − OPEX_t − Impuestos_t − Servicio_deuda_t Ingresos_t = AEP_neto · PML_t + Certificados de Energía Limpia (CELs) TIR: tasa r* tal que VAN(r*) = 0 Proyecto viable si TIR > WACC Payback descontado: primer año t* donde VAN acumulado ≥ 0

Implementación completa

import numpy as np from scipy.optimize import brentq def techno_economic(capex, aep_net, opex_fixed, opex_var, pml_series_25y, wacc, n=25, tax_rate=0.30, depreciation_years=20, debt_fraction=0.70): """ Calcula VAN, TIR, LCOE y flujos de caja del proyecto. pml_series_25y: array de 25 precios promedio anuales (USD/MWh) """ cash_flows = [] for t in range(1, n+1): revenue = aep_net * pml_series_25y[t-1] opex = opex_fixed + opex_var * aep_net deprec = capex/depreciation_years if t <= depreciation_years else 0 ebit = revenue - opex - deprec tax = max(0, ebit * tax_rate) fcf = ebit - tax + deprec # free cash flow cash_flows.append(fcf) cf = np.array(cash_flows) disc = np.array([(1+wacc)**-t for t in range(1, n+1)]) npv = -capex + np.sum(cf * disc) def npv_at_r(r): d = np.array([(1+r)**-t for t in range(1, n+1)]) return -capex + np.sum(cf * d) irr = brentq(npv_at_r, 0.001, 0.50) crf = wacc*(1+wacc)**n / ((1+wacc)**n - 1) lcoe = (capex*crf + opex_fixed) / aep_net + opex_var return {'NPV': npv, 'IRR': irr, 'LCOE': lcoe, 'cash_flows': cf}
25 · Validación de modelos

Validación y exportación — métricas y benchmarking

La validación cuantitativa es obligatoria antes de usar los resultados del modelo en decisiones de inversión. El módulo Validación y exportación de AERO compara predicciones de reanálisis y modelos ML contra observaciones de torre anemométrica, SCADA de parque o estaciones meteorológicas certificadas.

Métricas de validación

MAE

Error Absoluto Medio. MAE = (1/n)·Σ|ŷ_i − y_i|. Robusto a outliers. Unidades físicas (m/s, MWh). Objetivo: MAE < 0.5 m/s para velocidad de viento.

RMSE

Raíz del Error Cuadrático Medio. Penaliza errores grandes. RMSE = √[(1/n)·Σ(ŷ_i − y_i)²]. Siempre RMSE ≥ MAE.

Sesgo (Bias)

Bias = (1/n)·Σ(ŷ_i − y_i). Indica sobreestimación (+) o subestimación (−) sistemática. Objetivo: |Bias| < 0.1 m/s.

Skill Score

SS = 1 − RMSE_modelo/RMSE_ref. ref = persistencia o climatología. SS=1: modelo perfecto; SS=0: igual que referencia; SS<0: modelo peor.

R² de Pearson

Coeficiente de determinación. R² = 1 − SS_res/SS_tot. Mide varianza explicada. Objetivo: R² > 0.85 para predicción horaria.

Excedencia P50/P90

P50: producción esperada (mediana). P90: producción excedida el 90% del tiempo. Diferencia típica: 10–15% de AEP.

Bootstrap para estimación de incertidumbre

import numpy as np def bootstrap_metrics(y_true, y_pred, n_boot=2000, ci=0.90): """IC bootstrap para MAE, RMSE, Bias.""" n = len(y_true) mae_b, rmse_b, bias_b = [], [], [] for _ in range(n_boot): idx = np.random.randint(0, n, n) e = y_pred[idx] - y_true[idx] mae_b.append(np.mean(np.abs(e))) rmse_b.append(np.sqrt(np.mean(e**2))) bias_b.append(np.mean(e)) alpha = (1-ci)/2 return { 'MAE': (np.percentile(mae_b, alpha*100), np.percentile(mae_b, (1-alpha)*100)), 'RMSE': (np.percentile(rmse_b, alpha*100), np.percentile(rmse_b, (1-alpha)*100)), 'Bias': (np.percentile(bias_b, alpha*100), np.percentile(bias_b, (1-alpha)*100)) }

TOPSIS y AHP — Selección multicriterio de tecnología

Fundamento del método TOPSIS

TOPSIS (Technique for Order of Preference by Similarity to Ideal Solution, Hwang & Yoon 1981) rankea alternativas midiendo su distancia geométrica a la solución ideal positiva (A⁺) y negativa (A⁻) en el espacio normalizado de criterios. La alternativa ganadora es la más cercana a A⁺ y más lejana de A⁻.

Ec. 1 — Normalización vectorial

// Normalización por norma euclídea de cada columna j rij = xij / √( Σk xkj² )

Ec. 2 — Matriz ponderada

// w_j son los pesos AHP normalizados (suman 1) vij = wj · rij

Ec. 3 — Soluciones ideal y anti-ideal

A⁺ = { maxi(vij) si beneficio, mini(vij) si costo } A⁻ = { mini(vij) si beneficio, maxi(vij) si costo }

Ec. 4 — Distancias euclídeas

di⁺ = √( Σj (vij − A⁺j)² ) di⁻ = √( Σj (vij − A⁻j)² )

Ec. 5 — Coeficiente de proximidad (score TOPSIS)

// CC ∈ [0, 1]; CC=1 → alternativa ideal CCi = di⁻ / ( di⁺ + di⁻ )

Criterios activos en AERO OPEN CIM (7 criterios, layout de parque)

hours_near_cpmax ↑

Horas anuales en zona ≥95% del Cp máximo de la turbina. Indica qué fracción del año la turbina opera en su región de máxima eficiencia aerodinámica.

aep_p90_mwh ↑

Producción anual de energía al percentil 90 de excedencia (P90). Incorpora incertidumbre de recurso, estela, curva de potencia y pérdidas. Base conservadora para bankability.

lcoe_usd_kwh ↓

Costo Nivelado de Energía: PV(CAPEX + OPEX + desmantelamiento) / PV(energía neta). Estándar de industria para comparar tecnologías con diferente escala.

cp_effective_full_series ↑

Cp promedio sobre toda la serie histórica. Integra la curva de potencia real con la distribución de velocidades del sitio, sin truncar a una velocidad media.

capex_usd_per_installed_kw ↓

CAPEX total (turbinas + cable colector + cimentación) por kW instalado. Normalizar por kW evita premiar trivialmente instalar menos capacidad.

van_usd ↑

Valor Actual Neto bruto del proyecto (no normalizado por área ni por MW). Para un área fija, el VAN bruto mide el valor total extraíble de ese terreno.

factor_capacidad ↑

CF = AEP_P50 / (MW_instalado × 8760 h). Indica cuántas horas equivalentes a plena carga opera el parque por año.

Criterios excluidos del ranking (audit-only): BCR, TIR, payback descontado y ROI están perfectamente correlacionados con LCOE y VAN (ρ = ±1.000) cuando precio/tasa/OPEX% son constantes entre alternativas de una misma corrida — añadirlos duplicaría información sin aportar discriminación adicional. CAPEX total se excluye porque premiaría instalar menos turbinas en contradicción directa con AEP y VAN. Verificado en scripts/verify_technical_criteria_correlation.py.

AHP — Proceso Analítico Jerárquico (Saaty 1987)

Los pesos wj de TOPSIS se obtienen por AHP: el investigador construye una matriz de comparaciones por pares A (n×n), donde aij indica cuánto más importante es el criterio i respecto al j en la escala verbal 1–9 de Saaty. Los pesos son el autovector principal normalizado de A.

Ec. 6 — Vector de prioridades AHP

// Autovector principal de A, normalizado a suma = 1 A · w = λ_max · w → w = normalize( eigenvector(A, λ_max) )

Ec. 7 — Índice y Razón de Consistencia

CI = (λ_max − n) / (n − 1) CR = CI / RI(n) // RI: índice aleatorio de Saaty (1987) // Criterio de aceptación: CR < 0.10
Perfiles AHP en AERO OPEN CIM: La plataforma almacena dos elicitaciones documentadas del investigador (v1 sep-2026, CR=0.011; v2 oct-2026, CR=0.099) seleccionables con un clic en la pestaña MCDA. Ambas satisfacen CR < 0.10. El análisis SMAA integrado (500 muestras Dirichlet) evalúa la estabilidad del ganador ante perturbaciones de los pesos de ±10%, produciendo una frecuencia de victoria robusta por alternativa.
